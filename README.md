# Student Management System (Java)

A simple and efficient **Student Management System** built using **Core Java** with file handling.  
This project performs basic CRUD operations — Add, View, Search, Update, and Delete student records.

## 📌 Features
- ➕ Add Student  
- 📋 View All Students  
- 🔍 Search Student by ID  
- ✏️ Update Student Details  
- ❌ Delete Student    
- 🧼 Clean and structured OOP-based code (Student, Service, Main)

## 🛠️ Technologies Used
- **Java (Core Java)**
- **File Handling**
- **OOP Concepts**
- IDE: VS Code / IntelliJ / Eclipse (any)
